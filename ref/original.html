五种能量在你身上的比例

完整八字盘（专业）

一句话说清楚

中国传统认为，世界由五种能量组成：木、火、土、金、水。你出生那一刻的能量组合，就是你的「能量档案」。每一天、每两个小时也都有自己的能量。

  • 当天的能量正好是你缺的、需要的（幸运元素），这一天就更顺。
  • 当天的能量和你的本命能量相冲，就容易有波动，适合低调一点。
  • 能量和你的关系不同，这一天的「主题」也不同，比如收获日、表达日、充电日，建议也跟着主题走。

打开右上角「专业模式」可以看到背后的八字术语和完整计算表。

十种「日主题」对照

这个日历怎么算（专业）

  1. 按出生时间排出四柱（节气换月，立春换年，子时按 23 点起算）。
  2. 估算日主强弱：天干每个计 1 分，地支藏干本气 / 中气 / 余气计 1 / 0.5 / 0.3，月令再乘 1.6。日主同类加生我的五行占比 ≥ 50% 视为身强。假设
  3. 身强喜「我生、我克、克我」（食伤、财、官杀），忌印比；身弱反之。可在「我的能量」页手动改。假设
  4. 每天从 60 分起，按下表加减，再分五档：≥82 大吉（很顺），69–81 吉（顺利），52–68 平（平稳），41–51 小心（留神），≤40 凶（低调）。假设
  5. 时辰同理，以当天每个时辰的干支评分，并参考黄历的黄道 / 黑道。

还没定、需要你拍板的

  • 喜用神目前是按强弱粗算的。如果你有老师或测测给出的喜用神，直接在「我的能量」页改，日历会按你的设置重算。
  • 是否加入大运对流日的影响（现在只算原局、流年、流月）。
  • 建议文案目前偏职场。是否要分「工作 / 感情 / 财务 / 健康」几类分别给建议。
  • 卖给海外用户时是否要做完整英文版（现在只在元素和主题后附了英文词）。
  • 晚子时（23 点后）算当天还是次日，现在按次日算。
